# Technologies

## Purpose

Defines the technologies, platforms, tools, and technical capabilities used by the company.

This document enables AI Agents to accurately answer technology-related questions and explain technical solutions without exposing unnecessary implementation details.

---

## Responsibilities

- Define supported technologies
- Describe technical capabilities
- Explain platform compatibility
- Support technical conversations
- Maintain consistent technology information

---

## Must Include

- Programming languages
- AI models and providers
- Frameworks
- Automation platforms
- CRM integrations
- APIs
- Cloud platforms
- Communication channels
- Supported integrations

---

## Must Not Include

- API keys
- Internal architecture
- Security credentials
- Infrastructure details
- Proprietary implementation logic

---

- Company Knowledge

## Outputs

A structured technology reference that enables AI Agents to explain technical capabilities accurately.

---

## Dependencies

- Company
- Services
- FAQ

---

## Notes

This document should describe technologies from the customer's perspective whenever possible.

The AI should explain what each technology enables rather than focusing on low-level technical implementation.

Technology information should remain current and be reviewed whenever the company's technology stack changes.
