# Portfolio

## Purpose

Defines the company's completed projects, case studies, and proven experience.

This document enables AI Agents to demonstrate credibility by referencing relevant work and success stories when appropriate.

---

## Responsibilities

- Present completed projects
- Showcase business outcomes
- Demonstrate expertise
- Build customer trust
- Support service recommendations

---

## Must Include

- Project name
- Industry
- Client (if public)
- Project overview
- Business challenge
- Solution provided
- Technologies used
- Results achieved
- Related services

---

## Must Not Include

- Confidential client information
- Internal project documentation
- Proprietary code
- Financial agreements
- NDA-protected details

---

---

## Inputs

- Company Knowledge
- Services
- Technologies

---

## Outputs

A structured portfolio that enables AI Agents to reference relevant experience and build customer confidence.

---

## Dependencies

- Company
- Services
- Technologies

---

## Notes

Every portfolio entry should focus on business impact rather than technical complexity.

When multiple projects are relevant, the AI should reference only the most appropriate examples instead of listing all available projects.

Projects should only be referenced when they strengthen the recommendation or answer the user's question.
